# Workspace Agent Rules

## Browser Preview Mode
- **Always open website in Standalone Mode ("Open Standalone")**:
  - When asked to open the website or pages in the browser, always open the direct standalone page URL (e.g. `http://localhost:4200/oncourse-wireframe/pages/home.html` or the specific page under `oncourse-wireframe/pages/`) rather than the root iframe suite (`http://localhost:4200/`).
  - Rationale: The site is fully responsive, so opening standalone allows testing responsive layouts directly in the browser.
